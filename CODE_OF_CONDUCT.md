# Code of conduct

This project aims to keep technical discussion useful, evidence-driven, and welcoming to contributors with different levels of firmware and Zigbee experience.

## Expected behavior

- Be respectful and constructive when reviewing code, hardware evidence, or user reports.
- Critique technical claims and implementations, not people.
- Prefer reproducible evidence, logs, tests, and exact hardware identities over assumptions.
- Give contributors room to correct mistakes without ridicule or hostility.
- Keep issue and pull-request discussions focused on the project and the problem being solved.
- Respect privacy: do not repost credentials, private device identifiers, personal information, or security-sensitive details unnecessarily.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, threats, deliberate disruption, doxxing, or repeated bad-faith behavior are not acceptable in project spaces.

## Hardware and safety discussions

Firmware for mains-powered devices can create real-world risk. Do not pressure other contributors to perform unsafe flashes, bypass recovery requirements, or test unidentified hardware merely to produce evidence faster.

## Enforcement

Project maintainers may edit, hide, lock, or remove contributions that violate these expectations, and may restrict participation when necessary to keep the project safe and productive.

For sensitive conduct or security matters, contact the repository owner privately through GitHub rather than publishing private details in a public thread.
